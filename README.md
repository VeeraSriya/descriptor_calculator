# Descriptor Calculator

A beginner cheminformatics project built using Python and RDKit.

## Goal

Calculate molecular descriptors from SMILES strings.

## Features

- Interactive SMILES input
- Invalid SMILES handling
- Multiple molecule processing

## Descriptors Calculated

- Molecular Weight (MW)
- logP
- TPSA
- H-Bond Donors (HBD)
- H-Bond Acceptors (HBA)

## Technologies Used

- Python
- RDKit
- Google Colab

## Example Input

CC(=O)OC1=CC=CC=C1C(=O)O

## Example Output

MW: 180.16
logP: 1.31
TPSA: 63.6
HBD: 1
HBA: 3
